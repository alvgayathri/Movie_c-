# Movie Collection System

## Project Description:
The **Movie Collection System** is a C++ console-based project that allows users to manage their movie collection. Users can add movies, display all movies, and search for specific movies by title.

## Features:
- **Add Movie:** Add a movie with its title, genre, and release year to the collection.  
- **Display Movies:** View the list of all movies in the collection.  
- **Search Movie:** Search for a movie by its title and display its details.  
- **Exit:** Close the program.  

## How to Run the Project:
1. Open the project in **Dev-C++** or any C++ IDE.  
2. Compile the project (`MovieCollection.cpp`).  
3. Run the program.  

## Project Structure:
- **Class Movie:** Represents a single movie with details like title, genre, and release year.  
- **Class MovieCollection:** Manages a collection of movies and provides methods to add, display, and search for movies.  
- **Main Function:** Provides a menu-based interface for the user to interact with the system.
